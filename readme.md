# Лабораторна робота: Адаптивна верстка лендінгу Nothing

## Мета роботи
Закріпити навички сучасної фронтенд-розробки: побудова адаптивного інтерфейсу за принципом Mobile First, використання компонентної шаблонізації, архітектури стилів ITCSS, автоматизованої оптимізації графіки та налаштування збірки проєкту.

## Технологічний стек
* **Шаблонізація:** Pug (компонентний підхід, міксини для адаптивних зображень та SVG-спрайтів)
* **Стилі:** SCSS за методологією **ITCSS** (Settings, Tools, Generic, Elements, Objects, Components, Utilities) та іменуванням класів за **BEM**
* **Збирач проєкту:** Vite
* **Оптимізація графіки:** Sharp (автоматична генерація зображень у форматах `.avif`, `.webp`, `.jpg` для різних роздільних здатностей)
* **Лінтери та форматування:** Stylelint, Prettier

## Структура проєкту
```text
├── public/
│   └── images/            # Згенеровані оптимізовані зображення (AVIF, WebP, JPG)
├── scripts/
│   └── images.js          # Скрипт автоматичної оптимізації зображень через Sharp
├── src/
│   ├── assets/
│   │   ├── icons/         # Вихідні SVG-іконки для спрайту
│   │   └── raw-images/    # Вихідні зображення високої якості
│   ├── components/        # Pug-компоненти (header, footer, drawer, секції сторінки)
│   ├── layouts/           # Базовий шаблон сторінки
│   ├── mixins/            # Pug-міксини (picture, icon тощо)
│   ├── pages/             # Сторінки проєкту (index.pug)
│   └── styles/            # Архітектура стилів ITCSS (шари від 1-settings до 7-utilities)
├── index.html
├── package.json
└── vite.config.js
```

## Реалізований функціонал
* **Адаптивна сітка та брейкпоінти:** коректне відображення на мобільних пристроях, планшетах і десктопах.
* **Фіксована шапка сайту (`header`):** безшовна візуальна інтеграція з першим екраном (`hero`), інтерактивні стани при наведенні на контактний телефон (плавна поява номера) та іконку меню.
* **Мобільне навігаційне меню (`drawer`):** виїзна панель навігації, реалізована без зайвого JavaScript.
* **Секції контенту:** головний банер (`Hero`), блок рекомендованих товарів (`Recommended`), сітка категорій (`Browse Nothing products by category`), промо-банер, блок про бренд (`About us`) та форма зворотного зв'язку (`Contact us`) з валідацією полів.
* **Оптимізація продуктивності:** використання тегу `<picture>` із сучасними форматами `AVIF` та `WebP`, атрибутів `srcset`, `sizes` і відкладеного завантаження (`loading="lazy"`).

## Встановлення та запуск

1. **Встановити залежності:**
   ```bash
   npm install
   ```

2. **Згенерувати оптимізовані зображення:**
   ```bash
   npm run images
   ```

3. **Запустити сервер розробки:**
   ```bash
   npm run dev
   ```

4. **Зібрати проєкт для продакшену:**
   ```bash
   npm run build
   ```
